# RetailIntel

Retail and marketplace decision intelligence for inventory, margin, merchandising, and supplier decisions.

RetailIntel is designed as a Data Analyst / Analytics Engineer portfolio project, not a generic sales dashboard. The project will model commercial facts at explicit grains and turn them into stockout, overstock, margin, return, supplier, and reorder decisions.

Initial observations are reproducible synthetic data generated by this repository. No real retailer or customer data is claimed.
